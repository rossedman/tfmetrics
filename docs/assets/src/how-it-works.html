How it works
tfmetrics org · scan
1
discover GitHub orgs with name, topic and custom-property filters, or --local-dir of clones
2
classify root if it has a backend, cloud or configured provider; else child. Skips .terraform, examples, test
3
parse terraform-config-inspect plus a raw HCL walk. Never evaluated; errors become diagnostics
4
extract One facts/<org>__<repo>.json per repo, cached by commit SHA

∅Static by design

No terraform init, plan or state, and no cloud APIs. Only the HCL on disk is read, and count, for_each and variables stay as written.

!Parse errors are facts

A file that will not parse becomes a diagnostic and a tf_parse_errors count. The scan carries on with the rest of the repo.

↻Re-run without rescanning

Facts are cached by commit SHA. Change a weight or a label and re-aggregate saved facts without cloning anything.
